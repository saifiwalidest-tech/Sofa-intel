## نظرة عامة | Overview

**SOFA INTEL DZ** هي منصة بحث ومقارنة وتحليل ذكية متخصصة في سوق الأرائك والصالونات المعروضة للبيع داخل الجزائر. تعتمد المنصة على نظام متعدد الوكلاء يضم **18 وكيلاً متخصصاً** (Agent 00 إلى Agent 17) لتحويل البيانات غير المنظمة إلى قاعدة بيانات تجارية موثقة، مع الحفاظ على مصدر كل حقل (Field-Level Provenance) وعدم اختلاق أي مواصفات مفقودة.

### الميزات الرئيسية
- **نظام متعدد الوكلاء (18 Agents):** تنسيق مركزي، تحليل الرغوة (D20–D50, HR, Memory)، تحليل الخشب (Hêtre, Chêne, Pin, MDF...)، التنجيد والتعليق، الرؤية الحاسوبية، استخبارات الأسعار (توحيد الدينار/السنتيم)، تحسين Pareto، كشف المخاطر، التحقق من الحقائق، ومستشار شراء ذكي يفهم العربية والدارجة والفرنسية والإنجليزية.
- **مؤشر الجودة الفني (Sofa Quality Index / 100):** نموذج قابل للتخصيص يقيّم الرغوة (25)، الهيكل (25)، القماش (15)، التعليق (15)، التشطيب (10)، والضمان (10) — مع حساب نطاق الجودة المحتمل عند نقص البيانات ودرجة اكتمال المعلومات.
- **محرك البحث متعدد اللغات:** يدعم المرادفات الجزائرية (كنبة، صالون، موس 36، خشب الزان، `salon en L`, `salon marocain`, `mousse D36`, Darja Latin).
- **18 صفحة متكاملة:** تصميم Minimalist Premium بألوان الكحلي الداكن والأبيض العاجي والأخضر الزمردي ودرجات الخشب الطبيعية، مع دعم كامل لـ RTL/LTR والوضع الليلي/النهاري.
- **شفافية البيانات التجريبية:** جميع البيانات التجريبية موسومة بوضوح بعلامة `DEMO DATA` ولا تُعرض أبداً كعروض حقيقية مؤكدة.

## التشغيل السريع | Quick Start

### 1. المتطلبات
- Python 3.11+
- Node.js 18+ و npm
- (اختياري للإنتاج) Docker & Docker Compose

### 2. تشغيل الواجهة الخلفية (FastAPI Backend)
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
ستعمل الواجهة الخلفية على `http://127.0.0.1:8000` (وثائق Swagger في `/docs`).

### 3. تشغيل الواجهة الأمامية (Next.js Frontend)
```bash
cd frontend
npm install
npm run dev
```
ستعمل المنصة على `http://localhost:3000`.

### 4. التشغيل عبر Docker Compose
```bash
cp .env.example .env
docker compose up --build
```
